Third-party binaries bundled in the PocketAgent Android app
============================================================

None of the files below are built from this repository. They come from upstream
release artifacts and are kept in the repository so the APK can be built without
downloading anything. All checksums are SHA-256. Paths are relative to
app/src/main/assets/.

To check a file yourself: download the archive or package from the address given,
and compare checksums (for the Termux packages, unpack the .deb first).
