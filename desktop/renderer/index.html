上下文压缩
接口报「上下文超长」时，不管开没开自动压缩，都会先压缩再重试。
子 agent
子 agent 默认和任务用同一个模型、同一档思考，派去调研时可以换快一点的模型或低一点的档位。到了时长上限会停下手上的事、写个总结交回来；等你审批的时间不算。
AI 自动审批
只影响「AI 自动审批」：每次改文件、跑命令前让模型判断一下安不安全。用不着深度思考，默认用最低档，等得少。
工作目录以外
读文件不弹审批，改文件按审批模式走。落在这里的密钥目录（~/.ssh、~/.pocketagent 等）也不再问， 配了家目录就等于全都不问，风险自己掂量；bash 沙箱照旧读不到密钥。检查点只管工作目录，工作目录以外的改动撤销不了。
